# 🏰 SDL2 Tower Defense Game

![C](https://img.shields.io/badge/Language-C-blue.svg)
![SDL2](https://img.shields.io/badge/Library-SDL2-orange.svg)
![Status](https://img.shields.io/badge/Status-Active-success.svg)

A 2D Strategy and Tower Defense game built from scratch in **C** using the **SDL2** library. Manage your economy, build defensive structures, gather resources with woodmen, and survive incoming wave attacks across day and night cycles.

---

## 🎮 Features

* **Dynamic Day & Night Cycle:** Real-time lighting adjustments and progressive survival days where enemy waves spawn dynamically.
* **Diverse Towers:**
  * **Archer Tower:** Fires projectiles (arrows) at fast rates to target nearby enemies.
  * **Wizard Tower:** Deals area-of-effect (AoE) magic damage to groups of foes.
  * **Woodman Tower:** Spawns resource gatherers (woodmen) to harvest trees and boost your empire's economy.
* **Interactive Economy & Controls:** Build, upgrade, or sell structures (Ctrl + S), and zoom/pan smoothly across the grid map.
* **Custom Game States:** Includes interactive loading screens, gameplay loops, and pause/menu states.

---

## 🛠️ Technologies & Libraries

* **Language:** C
* **Graphics & Rendering:** SDL2, SDL2_image
* **Audio & Fonts:** SDL2_mixer, SDL2_ttf
* **Math & Utilities:** Standard C math and time libraries (`math.h`, `time.h`)
